# Ретроспектива 2026-10-18

## Сигналы

- Сессия: первый timeout выявил повторный перехват AskUserQuestion через PermissionRequest. Исправлено разделение событий, повторены настоящие 590 секунд.
- Сессия: русский Cmd+A/C/X/V зависел от раскладки. Нативный редактор переведён на физические keycodes, повторены реальные операции с кириллицей и emoji.
- Сессия: fullscreen cmux на macOS 27 не совпал с CG-рамкой экрана. Добавлен ограниченный пассивный AX fallback, проверен настоящий fullscreen.
- Сессия: однократный Swift-процесс возвращал устаревший NSWorkspace.frontmostApplication после sleep. Проверка свежим процессом показала корректное поведение. Изменения в рабочую логику по этому ложному сигналу не вносились.
- Сессия: automatic approval review запретил коммит без отдельного запроса пользователя. Повтор и обход не выполнялись. Реализация оставлена staged и сохранена постоянным patch.
- Git: предыдущие пять изменений Soon и навигации содержат исправления поведения после feature. Чужие календарные изменения сохранены отдельно.

## Выводы

- Повторяющийся приём: нативную интеграцию hooks проверять настоящим CLI, а не только входными JSON. В этой задаче это обнаружило второй waiter и уже разрешённый пользовательской политикой Write.
- Повторяющийся приём: наблюдатель фокуса должен обработать main run loop либо читать состояние в новом процессе. Иначе результат автоматизации может быть устаревшим.
- Слабое место процесса: итоговый план предполагал коммиты, но автоматическая проверка потребовала отдельный пользовательский запрос. Без пользователя безопасный результат – установленное приложение, staged source, постоянный patch и явная запись ограничения.

## Изменения правил

Правила проекта и скилы не менялись. Новых обязательных инструкций не требуется: обнаруженные ошибки исправлены в реализации и отражены в приёмке. Полная матрица IME, сна/часов и внешнего монитора остаётся открытой.
