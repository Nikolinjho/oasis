# Дизайн-код настроек Oasis

Документ задаёт оформление страниц настроек. Размеры основаны на существующих SettingsView, SettingsCard и ToggleRow. Исправления Claude Code и новая страница Codex должны следовать этим правилам.

## Размеры и отступы

| Элемент | Правило |
| --- | --- |
| Окно | 620 × 659 pt, содержимое прокручивается |
| Сайдбар | Ширина 200 pt, внутренний отступ 8 pt |
| Контент страницы | 20 pt со всех сторон |
| Между заголовком и группами | 16 pt |
| Заголовок группы и карточка | 6 pt, заголовок с отступом слева 4 pt |
| Карточка | Радиус 10 pt, фон SettingsPalette.cardBackground |
| Строка | Горизонтальный отступ 12 pt |
| Обычный тумблер | Высота 42 pt |
| Строка с многострочным описанием | Высота по содержимому, вертикальный отступ 8 pt |
| Разделитель | Отступ слева 12 pt |
| Строка с выбором | Вертикальный отступ 8 pt |
| Пороги | Кнопки 44 × 24 pt, вертикальный отступ строки 6 pt |

## Компоненты

SettingsCard рисует фон и группирует строки. Горизонтальный отступ задаёт компонент строки ровно один раз. Добавлять отступ всей карточке поверх отступов ToggleRow нельзя.

Подключение, пороги, выбор значения и конец рабочего дня используют общий отступ SettingsLayout.rowInset = 12 pt. Подписи всех строк внутри карточки начинаются на одной вертикали. Кнопки и переключатели располагаются у правой границы содержимого.

Превью звука передаётся через существующий параметр preview в ToggleRow. Внешняя кнопка рядом с ToggleRow нарушает общий отступ и не используется.

Заголовок страницы: иконка 26 pt, текст 19 pt bold. Основной текст строки: 13 pt. Описания: 11–12 pt, secondary, с переносом строк. Акцент берётся из SettingsPalette.accent.

## Зависимые настройки

Выключение модуля скрывает предупреждения и настройки раскрытого острова. Состояние подключения остаётся доступным. Выключение предупреждений скрывает пороги и звук. Выключение раскрытого вида скрывает прогноз. Выбор конца рабочего дня показывает время 16:00–23:00 с шагом 30 минут.

## Проверка оформления

Открыть Claude Code и Codex в светлой и тёмной теме. Проверить каждую группу, переключить зависимые настройки и прокрутить страницу до конца. Подписи, пороги, кнопки подключения и выбора времени должны иметь одинаковые отступы. Длинное описание подключения переносится без обрезки. Скриншоты обеих страниц служат подтверждением визуальной проверки.
