# Oasis · экраны на апрув

Актуальная версия – [v5](V5.md), `../oasis-all-screens-v5.html`. Сборщик теперь выпускает v5. Описание ниже относится к сохранённой версии v4.

81 макет в `../oasis-all-screens-v4.html`. Файл самодостаточный, сеть для просмотра не нужна. Страница позволяет переключать экраны, увеличивать их вдвое, открывать на весь экран и сохранять замечания к каждому.

## Основа размеров

- `ExpandedLayout.swift`: обзор и модули 768×216 pt, агенты 640×320 pt, компактная панель 560×288 pt, входящие 345×207 pt.
- `IslandGeometry.swift`: остальные раскрытые виды 345×175 pt и 32 pt навигации. Дополнительная строка громкости – 32 pt.
- `SettingsView.swift`: настройки 620×659 pt, сайдбар 200 pt, отступ контента 20 pt.
- Шрифты взяты из текущих SwiftUI-экранов: заголовки 15–18 pt, основной текст 12–13 pt, подписи 11–12 pt. Подписи меньше 11 pt не используются.
- В масштабе 100% один CSS px соответствует одному логическому пункту макета. Размеры не увеличиваются автоматически до ширины окна браузера.

## Что включено

Рабочие экраны острова, Claude Code, Codex, Soon, компактные состояния, HUD, уведомления, десять доступных страниц настроек и текущие диалоги подключения. Пять недоступных разделов настроек явно помечены. Два экрана приёма файлов – концепт новой функции из этюда v3.

Показ названия музыки предложен высотой 73,5 pt вместо текущих 51 pt, чтобы оставить место читаемой строке и персонажу. Это изменение отмечено непосредственно под макетом.

Пико занимает отдельную ячейку. Его Canvas обрезается по границе собственной области. В узких HUD и при подгонке выреза персонаж скрыт, чтобы не мешать показаниям. В покое остров совпадает с вырезом, в Mission Control скрывается вместе с Пико.

## Файлы и просмотр

- `screens.js` – перечень экранов, состояний и размеров.
- `review.css` и `review.js` – оформление и навигация макетов.
- `pico.js` – локальная версия движения из согласованного этюда v3, без фона и текста сцены.
- `template.html` – оболочка апрува.
- `build.py` – собирает самодостаточный HTML.
- `screens/` – PNG каждого экрана в масштабе 100%.
- `audit.js` – проверка геометрии через Playwright: наложения на камеру и область персонажа, обрезанный текст, переполнение и подписи меньше 11 pt.

```bash
python3 docs/design/oasis-approval/build.py
```

В длинных настройках и опросниках предусмотрена собственная прокрутка. Отметки апрува и комментарии хранятся в localStorage браузера, экспортируются JSON-файлом. Кнопки макета не выполняют команды и не отправляют внешние запросы.

Оригинальные размеры приложения и согласованное движение Пико имеют приоритет над общими рекомендациями навыка.
