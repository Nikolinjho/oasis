# Oasis: сравнение с текущим интерфейсом, v6

Сравнение v6 собирается локально в `../oasis-native-comparison-v6.html` из снимков SwiftUI. В каталогах `current/` и `refreshed/` сохранены индексы экранов. Предыдущие HTML-макеты v4/v5 остаются в архиве.

В сравнении 63 пары снимков оригинальных SwiftUI-представлений: все 10 раскрытых видов, пустые состояния, громкость, Soon, запросы Claude/Codex в двух размерах, музыкальные состояния, HUD, батарея, AirPods, события и все 15 страниц настроек. Это набор демонстрационных состояний, а не исчерпывающий прогон приложения. Настройки показаны с начала прокрутки, с изолированными демонстрационными настройками.

Обновление меняет только три цвета IslandPalette: фон, разделитель, акцент даты. Иконки, WaveformView, размеры текста, padding, spacing, frame, действия и состав исходных представлений не менялись. Пико добавлен Canvas-слоем только поверх пустого hover 203 × 90 pt. Отдельная панель позволяет проверить движение, скрытие в листьях и появление. На PNG-снимках кнопки приложения не работают, кадр волны статический. Интерактивны сравнение, апрув и персонаж.

Снимки сделаны через NSHostingView в отдельном временном приложении и захват окна macOS. ImageRenderer не подошёл: не рисовал содержимое некоторых ScrollView. Снимки не являются захватом установленного рабочего приложения. Временные окна не активировали рабочий Oasis. Продуктовый код и его настройки не менялись.

## Воспроизведение

Для воспроизведения возьми исходники `app/` из коммита `ba094db` и размести их рядом с папкой `docs/` в отдельной рабочей копии.

1. `python3 docs/design/oasis-native-review/prepare.py`
2. `CLANG_MODULE_CACHE_PATH=/tmp/oasis-sf-cache swift build --disable-sandbox --package-path /tmp/oasis-native-review --scratch-path /tmp/oasis-native-review/build`
3. `python3 docs/design/oasis-native-review/pack.py` упакует исполняемый файл `build/debug/Oasis` во временный `.app`, добавив оригинальные `app/Resources`, а также `Icons/claude.png` из установленного Oasis. Использованная точка входа сохранена в `main.swift`. Сборку приложения не устанавливать.
4. Запустить временное приложение с выходным каталогом `current`. Затем с каталогом `refreshed` и аргументом `refresh`. Нужен доступ к графической сессии и захвату экрана. Точка входа не запускает обычный AppDelegate и не меняет настройки рабочего приложения.
5. Выполнить `swift -module-cache-path /tmp/oasis-sf-cache docs/design/oasis-native-review/normalize-capture.swift <каталог>` для current и refreshed. Захват macOS иногда добавляет внешний край 1 pt. Скрипт убирает его без масштабирования. Затем `python3 docs/design/oasis-native-review/build.py`.
6. `python3 docs/design/oasis-native-review/verify.py`

Исходники копии: 258 файлов, 256 побайтно совпадают. Исключения: три цвета в IslandPalette и снятие private с переменной страницы настроек для выбора существующего экрана. Подробности в `source-verification.json`.
