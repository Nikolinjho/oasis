# Сценарии записи эталона

> Записи 26.09 закрыли музыку (из браузера), зарядку и раскрытие, схлопывание, HUD громкости и яркости и все экраны настроек. Разбор — `analysis/README.md`. Осталось: AirPods, Low Power, Focus, календарь, экран блокировки, свайпы и музыка из Music или Spotify.
>
> Можно писать в CleanShot, как в первый раз: 60 fps хватает. Удобнее одним файлом на сценарий, но и длинная запись подойдёт, я нарежу сам.

Цель — получить покадровые эталоны каждого состояния Alcove, чтобы агенты сравнивали свой рендер с оригиналом по кадрам, а не на глаз.

## Подготовка (один раз)

1. **Screen Recording для терминала:** System Settings → Privacy & Security → Screen & System Audio Recording → включить cmux (или терминал, из которого запускаешь).
2. **Частота дисплея:** System Settings → Displays → Refresh Rate → ProMotion (120 Гц). При 60 Гц запись пропустит половину кадров пружины.
3. **Обои однотонные и светлые.** Чёрный остров на чёрном фоне не измерить. Подойдёт `site/raw/wallpaper.webp` или просто серый.
4. **Тёмный и светлый режим:** основную серию пиши в тёмном, выборочно повтори в светлом.

## Как записывать

```bash
cd ~/oasis/capture
./record.sh hover-in 4        # имя сценария, длительность в секундах
./frames.sh recordings/hover-in.mov   # режет запись на кадры
```

`record.sh` пишет только полосу 700×140 pt по центру верха экрана — там весь остров со всеми состояниями. Начни действие через ~1 с после старта записи.

## Сценарии

Отмечай галочкой, что записал. Имя файла — первый столбец.

### Базовые взаимодействия
- [ ] `hover-in` — навести курсор на остров и держать 2 с
- [ ] `hover-out` — увести курсор
- [ ] `press` — нажать и отпустить
- [x] `expand-click` — клик, остров раскрывается полностью
- [x] `collapse` — закрыть раскрытый остров (увести курсор или кликнуть мимо)

### Музыка
- [x] `music-start` — запустить трек в Music, остров расширяется
- [x] `music-pause` — пауза: обложка и волна гаснут
- [x] `music-next` — следующий трек: переворот обложки
- [x] `music-expanded` — раскрыть плеер, держать 3 с (бегущая строка)
- [x] `music-stop` — закрыть плеер, остров сужается
- [ ] `music-swipe` — свайп для переключения трека (если включён в настройках)

### HUD
- [x] `volume-up` — несколько нажатий громкости вверх
- [ ] `volume-mute` — mute и обратно
- [x] `brightness` — яркость вверх и вниз

### Устройства и питание
- [ ] `airpods-connect` — открыть кейс AirPods рядом с Mac
- [x] `charger-connect` — подключить зарядку
- [ ] `charger-disconnect` — отключить зарядку
- [ ] `low-power` — включить Low Power Mode

### Календарь и Focus
- [ ] `calendar-upcoming` — событие через пару минут (заведи тестовое)
- [ ] `focus-on` — включить Focus (например, Work)
- [ ] `focus-off` — выключить Focus

### Экран блокировки
Запись экрана блокировки встроенными средствами не работает. Снимай на телефон в slow-mo (240 fps) со штатива, файл положи в `recordings/` вручную.
- [ ] `lock` — ⌃⌘Q
- [ ] `unlock` — разблокировка Touch ID, анимация замка

### Крайние случаи (достаточно скриншота)
- [ ] `fullscreen` — приложение на весь экран: остров прячется?
- [ ] `external-display` — внешний монитор без выреза (`forceSimulatedNotch`)
- [ ] `mission-control` — открыть Mission Control

## Что получится на выходе

```
recordings/<сценарий>.mov
frames/<сценарий>/0001.png …   # каждый кадр
frames/<сценарий>/contact.png  # сетка кадров на одном листе
```

Агенту для сравнения хватит `contact.png` и нескольких ключевых кадров: старт, пик перелёта, финал.
